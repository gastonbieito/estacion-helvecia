# Estación Helvecia

Siete misiones guiadas de micro:bit, en español, para el taller de programación.
Cada misión es un tutorial de MakeCode:

https://makecode.microbit.org/#tutorial:https://github.com/gastonbieito/estacion-helvecia/mision1

(cambiar `mision1` por `mision2` … `mision7`).

1. El faro de la estación: íconos y animación.
2. El panel de energía: botones, variables y SI.
3. El dado de meteoritos: agitar y azar.
4. El sensor de gravedad: inclinación.
5. El sensor de luz: nivel de luz y temperatura.
6. Esquivar asteroides: un videojuego con sprites.
7. La radio de la estación: mensajes entre placas.

Funciona con micro:bit V1 y V2.
